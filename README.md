# nxdk-examples
Example NXDK template functions for porting efforts, namely to assist in making ports feel closer to actual native Xbox games.

# Additional Resources
## Graphics Libraries
- [nxdk-gles11](https://github.com/Ryzee119/nxdk-gles11) - OpenGL ES 1.1 + OpenGL 1.5 (via gl4es)
- [pbGL](https://github.com/fgsfdsfgs/pbgl) - OpenGL 1.x (currently 1.2)

## Libraries
- [nxdk-sdl3](https://github.com/Ryzee119/nxdk-sdl3) - SDL3 (does not include SDL3_GPU)
